# Smart Deadline Recovery Assistant

Missed a deadline? Recover your plan, not your progress.

A Streamlit app that detects unfinished overdue tasks, recalculates
priority using transparent rules, and suggests a recovery schedule
for student approval.

## Tech Stack
- Python
- Streamlit
- Pandas

## Run locally
Install dependencies:

pip install -r requirements.txt

Start the app:

streamlit run app.py
